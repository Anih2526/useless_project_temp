### Project Description
PattiPani is a job-portal web app that connects humans with stray and local dogs for high-stakes field ops like scooter chasing, night patrolling, and chicken guarding. Users can inspect dog CVs complete with bite specs, teeth verification, and user reviews before hiring a dog executive for a mission.

### The Problem (that doesn't exist)
Stray dogs across Kerala are running wild, chasing scooters, guarding random boundary walls, and barking at night without any professional recognition, salary, or corporate structure. Meanwhile, citizens lack organized access to specialized canine muscle for local territory disputes and night ops.

### The Solution (that nobody asked for)
A localized "LinkedIn for Stray Dogs" where stray canine executives publish their professional resumes (CVs), including verified teeth count, bite force capability, street grip specifications, work history, and user endorsements so humans can hire them on demand.
